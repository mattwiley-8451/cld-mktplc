# cld-mktplc

A minimal Claude Code plugin marketplace.

## Usage

```
/plugin marketplace add mattwiley-8451/cld-mktplc
/plugin install hello-plugin@cld-mktplc
```

## Plugins

| Plugin | Description |
| --- | --- |
| hello-plugin | Adds a `hello` skill that greets the user |

## Creating plugins

See [docs/getting-started.md](docs/getting-started.md), or run `scripts/new-plugin.sh <name> ["description"]`.
